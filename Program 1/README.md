    Program 1 assignment for my Data Structures & Analysis Computer Science class.
    It's a simplistic "game-of-life" program that performs bitwise operations on the short-integer elements in an array. It uses a few simple task functions with a user-controlled main simulation loop, which contains a two-layered conditional statement to determine the operations performed on each value within the array. It recieves input from a user-selected file and outputs to both the console and to an output file of the user's choice.

[Instructions]
 1. Put the .cpp file into visual studio code, click run on the top of your screen, and click "run without debugging". Have the terminal open.
 2. Enter the input and output files of your choice when prompted. Input files contain over 6 numbers. Output files are completely empty.
 3. Type and enter "y" into the console to simulate the next generation. Type and enter anything you want to end the simulation.
